TinyKnight UI Kit

TinyKnight · kit d'interface

Les écrans du jeu redessinés avec les mêmes composants, déclinés pour le camp et les cinq zones. Changez de zone pour voir tout l'habillage suivre.

Icônes d'interface

Un fichier SVG par icône, au trait, dans la couleur du texte. Elles se recolorent toutes seules avec le thème.

Palettes des zones

Fond, panneau, panneau clair, filet, texte, accent, accent secondaire.

Utilisation

<link rel="stylesheet" href="tinyknight_ui.css">
<body class="tk" data-zone="mycelium">   <!-- camp, racines, mycelium, braises, givre, abime -->

<!-- coller une fois le contenu de tinyknight_icones.svg en haut du body, puis : -->
<svg class="tk-ic"><use href="#tk-inventaire"/></svg>

<!-- icône d'objet rendue depuis le modèle 3D -->
<button class="tk-slot rare"><img src="icones_objets/equipements/ambre_epee.png" alt="Épée d'ambre"><sub>2</sub></button>

<!-- bannière de zone en fond d'en-tête -->
<div class="tk-banner" style="background-image:url(bannieres_zones/banniere_mycelium.jpg)">…</div>
