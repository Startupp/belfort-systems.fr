# ASSETS - CONCEPTS - ARTS

Réserve graphique de TinKnight. Tout ce qui est produit pour le jeu arrive ici, trié, avant d'être copié dans le jeu (`ecorce/`). Rien de ce dossier n'est chargé par le jeu.

## Où regarder

| Dossier | Contenu |
|---|---|
| `01_concepts/` | planches concepts, cartes du monde, images de référence des décors |
| `02_modeles_3d/chevaliers/` | chevaliers (clips séparés du pack 1, puis versions complètes) |
| `02_modeles_3d/creatures/` | monstres : `pack1_statiques/`, `pack2_animes/<famille>/`, puis les suivants |
| `02_modeles_3d/decors/<zone>/` | décors à poser, un sous-dossier par pack |
| `02_modeles_3d/equipements/<panoplie>/` | casques, plastrons, boucliers, armes |
| `02_modeles_3d/pnj/`, `blocs/` | personnages non joueurs, blocs de terrain |
| `03_textures/<zone>/` | textures de zone 512 px (version en cours) |
| `04_herbes/<zone>/` | herbe et vie au sol |
| `05_interface/` | kit d'interface, icônes, fonds, illustrations de zone |
| `06_promo/` | illustrations, Play Store, publicités |
| `07_outils/` | pages de validation, démos, scripts |
| `_apercus/` | planches de contrôle de chaque lot |
| `_journal/` | une fiche par lot : date, contenu, état |
| `_alternatives/` | versions remplacées ou variantes non retenues |
| `INDEX.md` | liste des dossiers avec nombre de fichiers et poids |

## Règles

- Noms en minuscules, sans accents, mots séparés par `_`.
- Zones : racines, mycelium, braises, givre, abimes, puis canopee, mine, ruche, marais.
- On n'écrase jamais un fichier : l'ancienne version part dans `_alternatives/`.
- Un lot n'entre qu'après validation (page de validation du lot, réponse Oui).
- Les formats attendus par le jeu sont décrits dans la fiche « Formats TinKnight ».
