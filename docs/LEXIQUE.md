# Espace Breteuil — lexique des libellés (v5.5)

Objectif : qu'un enfant de 10 ans comprenne chaque bouton. Ce tableau liste les libellés **visibles**
de l'appli (titres, onglets, boutons, menus, messages), l'ancien texte, le nouveau, et ce que fait l'élément.

## Règles

1. **Pas de jargon** : ni « SharePoint », « OneDrive » seuls, « héritage », « bibliothèque », « groupe »,
   « tenant », codes de licence, « synchroniser », « téléverser », « cache ».
2. **Un verbe d'abord** pour les actions : « Voir le planning », « Ajouter un document »,
   « Choisir qui peut l'ouvrir ».
3. **Nom technique en second, en petit**, seulement s'il aide à faire le lien avec Microsoft :
   « Mes documents *(OneDrive)* », « Documents de l'équipe *(SharePoint)* ».
4. **Mêmes mots partout** : « document » (pas « fichier » dans les titres), « privé » (pas « réservé »,
   « restreint », « héritage cassé »), « Gestionnaire » (pas « propriétaire du site »).
5. **Une phrase courte** sous chaque tuile ; une seule action principale par carte.
6. Les écrans **Démos** (cachés, données fictives), **Détails techniques** (pour Damien) et
   **Rôles et administrateurs** (administrateur général) gardent quelques termes techniques : ils ne sont pas
   destinés au personnel.

## Les 3 niveaux (affichés dans Moi et au premier lancement)

| Niveau | D'où vient-il (droit réel Microsoft) | Phrase affichée |
|---|---|---|
| **Lecteur** | lecture seule sur le site du Château | Peut voir le planning et ouvrir les documents de l'équipe. |
| **Éditeur** | droit « ajouter / modifier des éléments » sur le site | Peut aussi ajouter, ranger et modifier des documents. |
| **Gestionnaire** | droit « gérer les autorisations » ou propriétaire du site | Peut aussi choisir qui peut ouvrir chaque dossier. |

Le niveau n'est **jamais** choisi par la personne : il est lu chez Microsoft. Si la lecture échoue,
l'appli affiche « Lecteur » (jamais plus que sûr) mais ne cache pas les boutons d'ajout.
