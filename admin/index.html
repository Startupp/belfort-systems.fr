Espaces chiffrés (ancien outil)

Génération et rotation des accès aux espaces clients chiffrés. Tout le chiffrement se fait dans ce navigateur : aucun mot de passe n’est transmis ni stocké en ligne.

Vos espaces clients

Ce registre est enregistré uniquement sur cet appareil. Exportez-le pour le conserver.

Créer un espace

Produit la page d’accueil chiffrée, le manifeste PWA, le service worker et les icônes.

Publier un document dans un espace

Le document est chiffré ici, puis déposé dans le dépôt. Personne ne peut le lire sans le mot de passe du client.

Changer le mot de passe d’un espace

Comment ça marche : le contenu est déchiffré ici avec l’ancien mot de passe, puis re-chiffré avec le nouveau. Chargez chacune des pages de l’espace, l’une après l’autre. Tant que les anciennes pages sont en ligne, l’ancien mot de passe continue de fonctionner : remplacez-les toutes.

Cet outil ne conserve aucun secret. La protection repose entièrement sur la robustesse du mot de passe de chaque espace.
